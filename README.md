# 燈下無明

「寫意」遊戲系列第四部的試玩版（v0.1）：一關〈紙宅 · 試夜〉。

紙糊的宅子，夜裡有魄。宅子收著你的兩方印：**名印**記著你的名字，**息印**記著你的一口氣。今晚是你的試夜，把兩方印取回來，自己走出大門。

- **出宅就贏**：到書房（西北）取名印、祠堂（東北）取息印，站在印臺旁按住 U；回玄關（南邊）按住 U 一秒半推開門閂，這時兩隻魄都會守在玄關；走出大門。
- **失魂就輸**：寒意滿一百就失魂。被咬時護心衣先擋（一開始擋得了三口），在魄身邊待久了也會冷；只有在火邊，寒意才會退。

「燈下無明」：燈照得到的地方，你看得清，魄也看得見你；燈外的黑暗，你什麼都看不見。掩了燈，眼睛會慢慢習慣，反而看得更遠。這一夜要學的，是什麼時候點燈、什麼時候掩燈。

純瀏覽器單頁，零依賴；字體走 Google Fonts（霞鶩文楷 TC）。

## 怎麼玩

| 按鍵 | 做什麼 |
| --- | --- |
| W A S D／方向鍵 | 走動 |
| 滑鼠 | 對準（不用滑鼠就朝走的方向） |
| J／左鍵 | 桃木劍 |
| K | 銅鈴（讀咒時也能搖） |
| L／右鍵 | 火符 |
| ：（分號鍵） | 點燈、掩燈 |
| 《 》（逗號鍵、句號鍵） | 《燼琅嬛》：借火、封戶 |
| U（按住） | 取印、推門閂 |
| P／Esc | 暫停（暫停時按 M 回主頁） |

左手 WASD 走位，其餘全在右手（U I O P J K L ：M《》；玩的時候 I、O、M 先空著，暫停時 U、I、O 是存檔、M 是回主頁）；用的是實體鍵位，中文輸入法開著、不按 Shift 都可以。

這一版只做了鍵盤與滑鼠。不用滑鼠時，劍與火符會自動對準看得見、在射程內最近的那隻魄（四角有紅括號）；動一下滑鼠就改成跟著滑鼠。

走過的地方會留下腳印，魄會循著新的腳印追（看得見時它頭上有「嗅」）。點燈走踩得重，五秒多才淡到聞不到；掩燈放輕腳步，三秒多就淡了。一直走它追不上；封戶擋得住、借火引得開。

開始畫面是一盞燈在紙宅裡飄過的長鏡頭。瀏覽器能跑 3D 時是立體的（three.js），跑不動或載不到就用平面的；右上角的「立體｜平面」看得到現在用哪一種，自動換成平面時會寫原因，也可以自己換（會記住）。網址加 `?flat=1` 這一次用平面的。窄螢幕（手機、側欄）上，選單在下面，上面看得到長鏡頭。

## 存檔

三格存檔，存在這個瀏覽器裡（`localStorage`）。開始畫面按 U、I、O 選一格，Enter 開始或繼續。這一局會自動存在自己那格：取印、推開門閂、暫停、切走視窗、關掉頁面時都會存。暫停時按 U、I、O，可以把這一刻抄到那一格當存檔點；要蓋掉另一局的存檔得按兩次。失魂後可以從存檔接著；出宅後那一格會留下出宅紀錄。暫停面板與結束畫面都有「回主頁」：先存好這一局再回開始畫面，那一格已經選好，Enter 就接著玩。瀏覽器存不了檔（例如無痕視窗）時照樣能玩，只是關掉就沒了。

## 檔案

- `index.html`、`style.css`：頁面與 HUD
- `src/rules.js`：所有數值
- `src/map.js`：紙宅地圖、格子走訪
- `src/engine.js`：規則與狀態（不碰畫面，Node 直接跑）
- `src/render.js`：畫面；`src/sfx.js`：聲音（WebAudio 合成）；`src/ui.js`：按鍵、HUD、主迴圈
- `docs/DESIGN.md`：設計書，含每個決定的理由與測試結果
- `tests/`：規則回歸、攻防對照、完整逃脫、壓力檢查；`scripts/`：瀏覽器煙霧測試、字體檢查、單檔打包

## 測試與打包

```sh
node tests/rules.cjs                 # 規則回歸，全部 PASS 才算過
node tests/review.cjs                # 攻防對照、完整逃脫、壓力檢查（結果寫進 tests/review-results.json）
node scripts/smoke.mjs               # 無頭瀏覽器，截圖在 shots/
python3 scripts/font-check.py        # 畫面上的字霞鶩文楷都有
python3 scripts/build-single.py      # dist/xieyi-deng.html（Artifact 用）
python3 scripts/build-single.py --page && node scripts/smoke.mjs "file://$PWD/dist/index.html"   # 驗單檔
```
