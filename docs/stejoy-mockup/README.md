## 首頁：第三張紙

- 接在《力透紙背》後面。類別多一顆「燈影 · 潛行」，「全部」從 2 變 3。手機上照原本的做法，三張由上往下排。
- 樣子：夜色的藍黑底（`#0d1018`），外面一圈暖黃的光。前兩張是淺紙、墨黑配紅色陰影，三張一眼分得開。
- 片段只露出燈照得到的一小圈；滑過或選到時，那一圈變大，像點燈。
- 標題「燈」最亮，「下、無、明」一個比一個暗：四個字自己就是「燈下無明」。
- 文案：類別「燈影 · 潛行」；標語「點燈見近 · 掩燈見遠」；一段話「紙糊的宅子，一盞手燈。取回名印與息印，自己走出大門。燈照得到的地方你看得清，魄也看得見你。」；狀態「敬請期待」。
- 「關於長風」加一句：「在《燈下無明》裡，宅子裡的東西都是字，燈照得到的才看得清。」
- **版面要跟著改**：三張排在 1080 寬裡，選到其中一張時，收起的《力透紙背》標題會被截掉。示意把首頁放寬到 1320（頂欄、開頭、「關於長風」、頁尾一起對齊），選到的那張 1.3、收起的 0.85。

## 介紹頁 `/dengxiawuming/`

整頁是夜色，標題前用一點燈，不用 SteJoy 的紅方塊。頂欄只有段落連結，沒有語言切換（只有繁體中文）。由上往下：

1. **開頭**：「寫意」系列 · 第四部；大標題「燈下無明」，與首頁那張紙一樣由亮到暗；「紙宅 · 試夜」與「點燈見近 · 掩燈見遠」；紅印「敬請期待」、「看實機」、「怎麼玩」。背景是立體長鏡頭的一格，只有燈籠附近亮。
2. **實機**：開始畫面的長鏡頭（示意用靜態畫面加播放鈕）。
3. **故事**：引文、名印與息印的那段話、「燈下無明」那段話；一條路線「書房 → 祠堂 → 玄關」；並排「出宅就贏」「失魂就輸」。
4. **玩法**：這一夜要學的四件事：點燈見近、掩燈見遠、腳印、噬，各配一張平面畫面。
5. **裝備**：劍、鈴、符、書、衣、燈，用遊戲裡的字當圖示，旁邊標按鍵。
6. **畫面**：平面、立體、第一人稱（標「試做」）三張並排；下面幾顆小標籤：一個關卡（試做）、四格存檔、鍵盤滑鼠或觸控、繁體中文。
7. **聯絡**：連到《墨畫蒼生》《力透紙背》。

文字大多照遊戲開始畫面與按鈕說明（`index.html` 的 `#start`、工具的 `title`）改寫，不說遊戲裡沒有的事。

## 真要做進 SteJoy 時

- SteJoy 的頁面由 `tools/site/*.py` 產生，改文字要改那幾支再重新產生：首頁在 `home.py` 的 `GAMES`、`KINDS` 與繁體 `TEXT` 加一部；介紹頁要照《力透紙背》的頁面另寫一支。
- 要錄一段開始畫面長鏡頭的片段（mp4 與 webm，加一張封面圖），放到 SteJoy 的 `assets/media/`，和另外兩部一樣。
- 首頁放寬到 1320 會動到另外兩張紙與其他語言頁的版面，要一起看過。
