實機

開始畫面的長鏡頭：一盞燈沿著一條路線，慢慢走過整座紙宅。遊戲實機畫面，還在做，畫面與內容都會再變。

故事

一燈能除千年暗，一智能滅萬年愚。

《六祖壇經》

紙糊的宅子，夜裡有魄。宅子收著你的兩方印：名印記著你的名字，息印記著你的一口氣。今晚是你的試夜，把兩方印取回來，自己走出大門。

燈照得到的地方，你看得清，魄也看得見你；燈外的黑暗，你什麼都看不見。掩了燈，眼睛會慢慢習慣，反而看得更遠。這一夜要學的，是什麼時候點燈、什麼時候掩燈。

  1. 書房西北

    站在印臺旁，按住「取」，拿回名印。

  2. 祠堂東北

    再取息印。兩印到手，兩隻魄都會守在玄關。

  3. 玄關南邊

    按住「取」一秒半推開門閂，走出大門。

出

出宅就贏兩方印都取回來，自己走出大門。

失

失魂就輸寒意滿一百就失魂。魄咬一口，護心衣先擋；只有在火邊，寒意才會退。

玩法

這一夜要學的四件事。

裝備

五件裝備，加一盞手燈。左手走位，右手出招。

  1. 劍
    桃木劍J

    打中能打斷魄的蓄撲，但擋不住下一次撲：打了就要退。

  2. 鈴
    銅鈴K

    把身邊的魄震開。不耗東西，但鈴聲穿得過紙牆，附近的魄都會過來。

  3. 符
    火符L

    朝前丟出去，碰到魄或牆就燒起來，附近的魄都會被燒到。

  4. 書
    《燼琅嬛》《》

    借火：在遠處點一團火，照路、取暖，也把魄引過去。封戶：封住廊口十秒，人與魄都過不去。

  5. 衣
    護心衣

    魄咬一口，護心衣先擋；一開始擋得了三口。

  6. 燈
    手燈：

    點燈、掩燈。看得清，還是不被看見，每一刻都要選。

畫面

同一座宅子、同一套規則，三種看法，玩到一半也能換。
